# Shared virtual environment for all four MediKiosk services — added
# 2026-09-11 so you only need ONE `venv` + ONE `pip install` for the whole
# project instead of four. This is the union of converse-module/,
# ocr-module/, voice-module/, and kiosk-backend/'s own requirements.txt
# files, deduplicated. Those four files are still each module's own source
# of truth if you ever want to run just one service in total isolation
# (e.g. a stripped-down deploy of only kiosk-backend) — this file doesn't
# replace them, it just lets run_all.py (and you) install everything once.
#
# Setup:
#   python3 -m venv .venv
#   source .venv/bin/activate        # Windows: .venv\Scripts\activate
#   pip install -r requirements.txt
#
# run_all.py looks for this venv first (repo root .venv) and only falls
# back to a per-module .venv/ if it's missing, so existing per-module
# venvs from before 2026-09-11 keep working unchanged.
